data-agent-gauntlet

An open-source way to decide which AI coding agent to trust with your data platform.

Agents such as Claude Code, Kiro, Codex and Cursor now write SQL and design warehouse tables. This harness gives them real tasks on Amazon Redshift Serverless and lets the warehouse, not the agent, decide pass or fail. It runs a baseline arm and a skills arm so you can measure what agent skills actually change.

  • 20 tasks across query writing, schema design, loading, troubleshooting and optimization
  • Reads sys_query_history to count failed statements and PostgreSQL habits that break on Redshift
  • Sandboxed by default: scoped IAM role, daily RPU cap, one-command teardown
